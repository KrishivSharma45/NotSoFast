# NotSoFast 🛑

Detects scam messages, phishing links and fake Unified Payments Interface (UPI) QR codes before you click, pay or reply.

## Why
Scam texts, fake payment requests and malicious QR codes are everywhere. NotSoFast helps you check before you trust.

## Planned features
- [ ] Scam message detection (urgency, fake offers, impersonation patterns)
- [ ] Suspicious link analysis (lookalike domains, URL shorteners, known phishing patterns)
- [ ] UPI QR code checker (decode the QR and flag suspicious payee details)
